# AI Learning Journey

Hi! 
This repo is my personal learning journey from Python basics all the way to starting with AI and machine learning.  
I wanted a place to **keep track of what I learn, the small projects I make, and how I improve over time**.

---

## What’s in this repo

### 1️⃣ Python Basics
Small projects to get comfortable with Python:
- **Calculator** – Practiced loops, conditionals, and functions.  
- **Guessing Game** – Learned random numbers, loops, and input handling.  
- **Number Converter** – Converted numbers between different formats.

### 2️⃣ Problem Solving
Simple challenges to improve logical thinking:
- Prime number checker  
- Fibonacci series generator  
- Pattern printing  
- Mini quiz app

### 3️⃣ Object-Oriented Programming (OOP)
Projects to understand how to organize code like real systems:
- Bank management system  
- Library management system  
- Student record system

### 4️⃣ Data Handling
Playing with real data:
- CSV file data cleaner  
- Student marks analysis  
- Simple visualizations using Matplotlib and Seaborn

### 5️⃣ Small Machine Learning Experiments
Just starting with ML here:
- Linear regression on house prices (small dataset)  
- Student performance predictor (basic dataset)

Through these projects, I’ve learned:

- Debugging and solving errors
