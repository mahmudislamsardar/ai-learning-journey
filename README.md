# AI Learning Journey

This repository documents my **step-by-step journey from Python fundamentals to artificial intelligence**.  
It shows the projects, experiments, and learning I did to build a strong foundation in coding, problem-solving, and AI.

---

## 📚 Repository Structure

### 01 - Python Foundations
Small projects to strengthen programming basics:
- **Calculator** – Practice loops, conditionals, and user input.
- **Guessing Game** – Learn random module, loops, and input handling.
- **Number Converter** – Convert numbers between different formats.

### 02 - Problem Solving
Projects that focus on **logic and algorithms**:
- Prime number checker
- Fibonacci series generator
- Pattern printing
- Mini quiz applications

### 03 - Object-Oriented Programming (OOP)
Projects to understand **real-world system design**:
- Bank management system
- Library management system
- Student record system

### 04 - Data Handling
Projects with **data cleaning and analysis**:
- CSV file data cleaner
- Student marks analysis
- Simple data visualization

### 05 - Machine Learning (small experiments)
Early experiments applying ML concepts:
- Linear regression on house prices (small dataset)
- Student performance predictor (basic dataset)

This repository is designed to track my **progressive learning path**:
